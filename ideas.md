# Project Graveyard — Fikir Defteri

## 🔴 Yüksek Öncelik (Core)

| # | Özellik | Açıklama |
|---|---|---|
| 1 | **Proje Arama (Search)** | Projeler çoğaldıkça bulması zorlaşır, dashboard'da hızlı metin arama |
| 2 | **Sıralama (Sort)** | İsim, tarih, progress, son güncelleme'ye göre sıralama desteği |
| 3 | **Dashboard'dan Hızlı Status Değiştirme** | Proje kartında direkt status dropdown'ı ile detay sayfasına gitmeden güncelleme |
| 4 | **Proje Milestone / Checklist** | Hedefe ulaşma yolunda adımları işaretleme, tamamlanma oranını milestone'lara göre hesaplama |

## 🟡 Orta Öncelik (Engagement)

| # | Özellik | Açıklama |
|---|---|---|
| 5 | **Resurrection İstatistikleri** | Kaç proje tekrar canlandı, canlananların başarı oranı, "graveyard → alive" dönüşüm hikayeleri |
| 6 | **Activity Heatmap** | GitHub kontribution graph benzeri, hangi günler projelerle ilgilendiğini gösteren ısı haritası |
| 7 | **Progress Timeline Görselleştirme** | Projenin ömrü boyunca status değişikliklerini interaktif timeline'da gösterme |

## 🟢 Düşük Öncelik (Extended)

| # | Özellik | Açıklama |
|---|---|---|
| 8 | **Export / Backup** | Tüm projeleri JSON/CSV export etme |
| 9 | **PWA Desteği** | Mobilde "add to home screen" ile native-like deneyim |
| 10 | **Public Proje Paylaşımı** | Tek bir projeyi herkese açık link olarak paylaşma (portfolyo amaçlı) |

## ✨ Şıklık Katacak Özellikler

| Özellik | Açıklama |
|---|---|
| **Mezar Taşı Tema Kartları** | Her status için farklı "gravestone" görünümü — abandoned = yosunlu taş, active = canlı çiçekli, completed = mermer anıt gibi. Uygulamanın ismiyle tam uyumlu, çok karakterli |
| **Status-based Ambient Background** | Proje detay sayfasında status'e göre değişen gradient/pattern arkaplan |
| **Animated Dashboard Transitions** | Filtre değiştirince kartların smooth geçiş animasyonu, status güncellemelerinde mikro animasyonlar |
| **3D Graveyard Scene** | Dashboard üstünde Three.js ile basit bir 3D mezarlık sahnesi — archive/gömülen proje sayısına göre mezar taşları eklenir |
| **"Ghost" Empty States** | Boş durumları klasik "no projects" yerine uygulama konseptine uygun hayalet/tabu temalı görsellerle süslemek |
| **Proje Kartlarına Cover Fotoğraf** | Her projeye optional cover image, dashboard grid görünümünde çok daha premium durur |
| **Achievement / Badge Sistemi** | "İlk projeni gömdün 🏆", "5 projeyi canlandırdın 🧟", "10 projeyi tamamladın 🎯" gibi rozetler |
